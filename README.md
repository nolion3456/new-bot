# Discord 多功能机器人

这是一个使用 Node.js 和 discord.js 构建的 Discord 机器人。

## 基础指令

- `/ping`：检查机器人是否在线并显示延迟。
- `/help`：查看可用指令。
- `/audit-channel`：由拥有“管理服务器”权限的成员打开私密后台管理面板。

## Giveaway 抽奖功能

### 创建与发布

```text
/giveaway create duration:1d winners:1 prize:奖品 channel:#抽奖频道
```

执行后不会立即公开发布，而是先发送只有指令发送者看得到的私密设置面板。管理员可以：

- 选择一个额外身份组；拥有该身份组的成员中奖权重为 2 倍，但其他成员仍然可以参加；
- 不选择身份组，让所有成员以相同权重参加；
- 选择“发布抽奖”或“取消”。

`channel` 参数可以省略；省略时会使用执行 `/giveaway create` 的当前频道。发布后的抽奖使用 🎉 按钮参加，不使用 reactions。抽奖 Embed 会显示奖品、获奖人数、参加人数和 Discord 相对倒计时；到期后自动抽取并在频道公开 @ 获奖者。

### 管理指令

- `/giveaway end message_id:<消息ID>`：提前结束并抽奖。
- `/giveaway reroll message_id:<消息ID>`：对已结束抽奖重新抽取获奖者，优先排除上一轮获奖者。
- `/giveaway list`：列出本服务器进行中的抽奖。
- `/giveaway delete message_id:<消息ID>`：删除抽奖消息和保存的数据。

## 迷你币余额系统

- `/balance`：公开显示执行者当前的迷你币余额，并提供“加币”和“减币”按钮。可选填写 `user` 查看其他玩家余额，查看不需要管理员权限。
- 只有拥有“管理服务器”权限的成员可以使用按钮调整余额；金额通过弹窗输入。
- 所有余额统一支持最多 2 位小数，也允许余额为负数；例如 `10.25`、`-5.5`。加币和减币输入也支持带正负号的金额，最终结果会统一四舍五入到 2 位小数。
- 调整后会在公开频道显示被调整成员、增加或减少的数量、调整后的余额和操作者。
- `/balance-name name:<名称>`：管理员修改本服务器的币名称，默认名称为“迷你币”。
- `/transfer user:<成员> amount:<金额>`：成员转账迷你币给指定成员。转账人余额会扣除对应金额，收款人余额会增加对应金额；收款人会收到私讯通知，转账也会进入余额变化后台日志。
- `/exchange`：管理员私密设置迷你币与大面额“余额”的双向兑换数量、兑换比例和开放状态，然后在当前频道发布公开兑换面板。成员点击兑换后会私密完成操作。
- 数据保存在 `data/balances.json`，支持不同服务器分别保存迷你币、余额与币名；兑换规则保存在 `data/exchange.json`。

## 商城系统

- `/shop`：管理员先收到私密商城管理面板，可以上架商品、修改名称与说明、调整价格、调整库存、下架、重新上架或删除商品，最后在当前频道发布公开商城面板。
- 商品价格统一使用大面额“余额”；库存填写 `-1` 代表无限数量，`0` 代表售罄。
- 成员点击公开面板的“逛商城”按钮后，会以私密方式查看商品并选择购买；可以切换“只看有货”或“查看全部”，查看全部时也会显示售罄商品。
- 购买时可以输入购买数量，不再限制一次只能购买 1 件；机器人会计算总价，并先显示二次确认，成员确认后才会扣除总价余额并按数量减少库存。余额不足、商品下架或库存变化都会阻止购买。
- 商品详情同时提供“加入购物车”和“立即购买”；成员可以把多种商品、不同数量加入购物车，最后统一确认、一次扣款、一次扣库存，并自动建立一个包含全部商品的合并工单。
- 商城数据保存在 `data/shop.json`，机器人重启后会恢复商品、价格、库存和上下架状态。
- 成员购买成功后会自动创建一个私密工单频道；未认领时命名为 `购买物品-用户名`，管理员点击“认领”后改为 `处理中-用户名`。工单内会显示购买成员、商品、数量、总价，并提供“认领”和“关单”按钮。
- 关单后会提供“重新开单”“生成记录”和“直接关单”三个选项；生成的 HTML 记录文件会发送到管理员设置的记录频道，可直接用浏览器打开或下载，直接关单会删除工单频道。
- 工单面板现在提供“完成订单”“取消订单”“编辑商品”“关闭订单”和“填写优惠券”；完成订单会在工单内公开发送评价面板，但只有开单成员可以提交，评分为 1—5 星并支持文字内容。
- `/shop` 管理面板可以设置评价发送频道和优惠券。优惠券支持百分比折扣或固定金额折扣、总使用次数限制、每人限用一次；成员填写优惠券后会立即退回折扣金额。
- `/ticket` 只能在工单频道内使用，管理员可用私密面板调整等待处理、处理中、完成、取消、关闭状态，并添加其他成员查看工单。管理员取消订单时可以选择退款或不退款；成员取消订单会退回余额并恢复库存。
- 管理员可以在 `/shop` 私密管理面板选择工单分类和记录频道；未设置工单分类时，工单会创建在服务器未分类频道区域的最上方。

## 迷你币拍卖

- 管理员使用 `/auction create`，在私密弹窗中填写拍卖物品、起始价格、每次最低加价和可选时长。
- 机器人会在当前频道发布拍卖面板；成员点击“出价”按钮并输入迷你币价格。
- 新出价必须至少达到当前价格加上最低加价，且出价者余额必须足够；暂时不会立即扣款，拍卖结束时从最高出价者余额扣除。
- 管理员可以使用 `/auction end` 提前结束；如果设置了时长，时间到了会自动结算。拍卖数据保存在 `data/auctions.json`，机器人重启后会恢复计时器。
- 目前拍卖币种使用本服务器的余额名称（默认迷你币），后续可以扩展其他币种。

余额面板已改为资产卡片样式；加币或减币后，公开记录会按“被调整成员、变更类型、变更数量、变更后余额、操作者”逐行显示。

## 迷你币小游戏

- 管理员使用 `/gamble` 后会收到私密设置面板，可以分别设置老虎机、猜大小和猜硬币正反的最低下注金额与中奖概率；点击“确认发布”后，机器人会在当前频道发布公开游戏大厅。
- 成员点击公开大厅的“开始游戏”后，会收到私密游戏选择面板；选择游戏后，再在私密弹窗中输入自己想下注的金额。
- 成员下注金额不能低于管理员设置的最低下注金额，也不能超过自己的余额；中奖返还实际下注金额的 2 倍，未中奖则扣除实际下注金额。
- 成员选择游戏、输入下注、中奖或失败结果全部通过私密面板显示，不会把个人赌博结果公开到频道。
- 猜硬币正反会私密选择“正面”或“反面”，然后输入下注金额并显示硬币结果。
- 下注金额支持最多两位小数，中奖概率为 0 到 100 的整数。
- 游戏配置保存在 `data/gambling.json`。本系统只使用服务器内的迷你币，不涉及现实货币或提现。

## UTC+8 签到与每日奖励

- 管理员使用 `/checkin` 后会收到私密设置面板，可以调整每日基础奖励、连续签到奖励和每周奖励；点击“确认”后，机器人会在当前频道发布公开签到面板。
- 普通成员点击公开签到面板的“签到”按钮，按照 UTC+8 日期每天领取一次；每天跨过 00:00 后可以再次领取。
- 每日基础奖励支持固定金额或随机金额范围；连续签到奖励按连续天数计算；每周签到达到设定天数后发放一次额外奖励。

签到奖励支持最多 2 位小数；每日基础奖励范围与额外奖励不能设置为负数，但余额本身仍然支持负数。签到数据保存在 `data/checkins.json`。

抽奖数据保存在 `data/giveaways.json`，机器人重启后会读取未结束抽奖并恢复计时器。数据按服务器和抽奖 ID 隔离，支持多个服务器和多个并行抽奖。

## 审计后台

执行 `/audit-channel` 后，面板提供三个下拉菜单：先选择后台文字频道，再为当前选中的频道选择要显示的日志类型，最后选择添加、移除或刷新操作。最多同时配置 3 个后台审计频道，每个频道可以显示不同内容。例如一个频道只开启成员日常行动，另一个频道只开启余额变化。可选日志类型包括身份组变动、昵称变动、消息编辑、消息删除、成员加入、成员离开、禁言、封禁、踢出和余额变化；关闭某项后，该项事件不会发送到当前频道。

余额变化日志会按成员、变化类型、变化数量、变化前余额、变化后余额、变化原因和操作者逐项记录；管理员加减余额会显示具体管理员，成员转账会显示转账成员，签到奖励、拍卖结算、兑换及小游戏扣款或派奖会显示对应系统原因。所有通过余额系统产生的变化都会进入余额变化日志。审计配置会保存到配置消息中，机器人重启后会恢复每个频道各自的日志类型。

消息编辑和删除日志会记录文字、嵌入内容、引用消息和 Discord 转发消息快照（如果 Discord API 提供该资料）。没有图片或附件时不会显示空的媒体栏；存在图片或附件时，链接会放在日志消息正文（Embed 外部），避免塞进面板字段影响阅读，显示风格更接近 Dyno。

成员加入和离开日志会显示成员帐号创建时间、成员标识以及加入或离开时间。新增后台日志包括成员被禁言、解除禁言、封禁、解除封禁和踢出，并显示目标成员与执行者；禁言日志还会显示禁言结束时间、禁言时长和 Discord 审计日志中的原因。消息编辑日志会显示编辑前文字、编辑后文字、发送者、频道、发送时间和编辑时间。消息删除日志会显示发送者、删除者、频道、发送时间和删除时间。

Discord 没有“unkick/解除踢出”这个审计事件：踢出后成员重新加入只能算成员加入，无法可靠判断是否属于“解除踢出”，因此该选项会在面板中说明不可用，不会伪造日志。

## Discord Developer Portal 设置

为了读取成员进出、消息编辑与删除事件，请开启：**Server Members Intent** 和 **Message Content Intent**。

邀请机器人时，至少授予 View Channels、Send Messages、Embed Links、Read Message History、View Audit Log、Moderate Members、Ban Members 和 Kick Members 权限。使用管理指令需要 Discord 的 **Manage Server（管理服务器）** 权限。

## 本地运行

```bash
npm install
cp .env.example .env
# 编辑 .env，填入 DISCORD_TOKEN
npm start
```

## 环境变量

- `DISCORD_TOKEN`：Discord Bot Token，必填。
- `DISCORD_GUILD_ID`：可选。填写后会立即向指定服务器注册指令；不填写则注册为全局指令。
- `PORT`：可选，默认 `3000`。

审计配置与抽奖数据会写入本地 JSON 文件。请确认部署平台的文件系统会保留运行时文件；如果平台使用临时文件系统，重启或重新部署后需要改用持久化磁盘或数据库。
